# 猎人 Playbook — 6人局

## 核心定位
死亡时开枪带走一个狼人，震慑狼队，保护好人阵营

## 首夜策略

**猎人首夜无行动**，但需要做好准备：
- **记录发言** - 观察每个人的发言特点
- **锁定嫌疑** - 记录最可疑的玩家，为开枪做准备
- **评估风险** - 如果被狼击杀，准备好开枪目标

## 发言策略

**何时跳猎人**:
- **被怀疑时** - 如果自己被怀疑要被投票出局，可以跳猎人震慑
- **关键时刻** - 当局势混乱，需要稳定场面时跳猎人
- **不要过早跳** - 猎人跳太早=狼人会避免投你，减少开枪机会

**跳身份后的优势**:
- **震慑狼队** - 狼人不敢直接投票出局猎人（怕被开枪带走）
- **带领节奏** - 猎人可以大胆发言，引导投票
- **配合预言家** - 与预言家形成神职联盟

**未跳身份时的发言**:
- **独立分析** - 观察各方发言，记录可疑点
- **不要太激进** - 避免成为狼人首要目标
- **保持灵活** - 随时准备跳猎人自证

## 投票策略

**投票原则**:
1. **可以大胆投票** - 猎人不怕被投出局（可以开枪带走一个狼人）
2. **集中火力** - 跟随预言家的验人结果，投出狼人
3. **不要平票** - 平票浪费一轮，猎人要带头投票

**开枪目标优先级**:
1. **已验的狼人** - 如果预言家验出狼人，优先开枪带走
2. **最可疑的玩家** - 发言矛盾、逻辑混乱的玩家
3. **带节奏的玩家** - 影响力大、可能是狼人的玩家

**开枪时机**:
- **被投票出局时** - 投票被放逐，可以开枪带走一人
- **被狼人击杀时** - 如果被狼人夜间击杀，也可以开枪带走一人

## 常见陷阱

**❌ 不要做的事情**:
1. **过早跳身份** - 猎人跳太早=狼人会避免投你，浪费震慑价值
2. **开枪打错** - 开枪打死好人=直接导致好人阵营崩盘
3. **不敢投票** - 猎人不怕被投，应该大胆投票
4. **盲目开枪** - 开枪前要确认目标，不要凭感觉开枪

**✅ 成功的猎人行为**:
- 隐藏身份到关键时刻
- 被怀疑时跳猎人震慑
- 开枪目标明确（已验的狼人/最可疑的玩家）
- 与预言家配合，形成神职联盟

## 特殊技巧

**震慑战术**:
- 跳猎人后，狼人不敢直接投票出局你
- 利用这个优势大胆发言，带领好人阵营

**开枪决策**:
- **被投票出局**: 开枪带走最可疑的狼人（优先已验的狼）
- **被狼人击杀**: 开枪带走最可疑的玩家（通常是发言矛盾者）

**配合预言家**:
- 如果预言家验出狼人，跳猎人支持预言家
- 引导好人集中投票，投出已验的狼人

**最后一轮开枪**:
- 如果游戏进入最后一轮，猎人开枪可以直接决定胜负
- 确保开枪目标是狼人，否则好人直接输掉游戏
