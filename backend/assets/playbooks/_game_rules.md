# 6人局基本规则

## 角色配置

**女巫模式 (classic_6_witch)**
- 2名狼人
- 1名预言家
- 1名女巫
- 2名村民

**猎人模式 (classic_6_hunter)**
- 2名狼人
- 1名预言家
- 1名猎人
- 2名村民

## 夜间行动顺序

1. **狼人击杀** - 狼人协商并选择一个目标
2. **女巫行动** (女巫模式) - 得知受害者，决定是否救人或毒人
3. **预言家验人** - 查验一名玩家的身份

## 白天流程

1. **晨间公告** - 宣布昨夜死亡玩家
2. **轮流发言** - 所有存活玩家依次发言
3. **投票放逐** - 每人投票选择要放逐的玩家
4. **执行放逐** - 票数最多的玩家被放逐（平票则无人出局）

## 胜利条件

**好人阵营**: 所有狼人死亡
**狼人阵营**: 狼人数量 ≥ 好人数量

## 特殊规则

- **女巫救人**: 解药只能在看到当晚受害者后使用，首夜可自救
- **女巫毒人**: 毒药可以在同一夜使用，被毒杀者直接死亡
- **猎人开枪**: 被投票放逐时可开枪带走一人，但被毒杀无法开枪
- **预言家验人**: 每晚验一人，得知"好人"或"狼人"阵营
- **发言顺序**: 从死者下一位开始，顺时针发言
- **投票规则**: 公开投票，票数相同则平票无人出局
