# 村民 Playbook — 6人局

## 核心定位
分析发言，找出狼人，保护神职，正确投票

## 首夜策略

**村民首夜无行动**，但需要做好准备：
- **记录死亡信息** - 第二天早上看谁死了
- **分析击杀目标** - 狼人为什么杀这个人？是神职还是强势玩家？
- **准备发言** - 思考第二天的发言策略

## 发言策略

**发言原则**:
- **贡献分析** - 即使没有特殊能力，也要贡献逻辑分析
- **引导讨论** - 提出关键问题，帮助好人阵营找到狼人
- **不要沉默** - 沉默的村民=容易被怀疑成狼人

**是否伪装神职**:
- **伪装预言家** - 高风险，可能吸引狼人击杀（保护真预言家）
- **伪装其他神职** - 震慑狼队，让狼人不敢轻易刀你
- **不伪装** - 坦诚村民身份，用逻辑说服其他人

**何时表明村民身份**:
- **被怀疑时** - 坦诚说"我是村民"，用逻辑自证
- **投票前** - 表明身份，请求神职保护/引导

**发言要点**:
1. **分析死者身份** - "昨晚XX死了，可能是神职"
2. **指出发言矛盾** - "YY的发言前后矛盾，可疑"
3. **提出投票建议** - "建议今天投ZZ，理由是..."
4. **配合神职** - 如果预言家跳出，支持预言家的验人结果

## 投票策略

**投票原则**:
1. **跟随可信赖的神职** - 如果预言家或其他神职跳出，优先跟随他们的判断
2. **独立思考** - 如果没有神职引导，根据发言分析投票
3. **集中火力** - 避免平票，集中投最可疑的玩家

**投票目标优先级**:
1. **已验的狼人** - 预言家验出的狼人
2. **发言矛盾者** - 前后发言不一致的玩家
3. **带节奏失败者** - 试图误导好人的玩家

**如何判断狼人**:
- **投票一致** - 两个人投票总是一致，可能是狼队
- **逻辑混乱** - 发言前后矛盾，试图混淆视听
- **过度激进** - 过度带节奏，可能是悍跳的狼人
- **过度沉默** - 几乎不发言，可能是隐藏的狼人

## 常见陷阱

**❌ 不要做的事情**:
1. **盲目跟票** - 不思考就跟随别人投票=可能被狼人利用
2. **不发言** - 沉默的村民容易被怀疑成狼人
3. **投票分散** - 平票=浪费一轮，必须集中投票
4. **被假跳误导** - 狼人假跳预言家，要仔细辨别真假
5. **自相矛盾** - 前后发言冲突=被怀疑成狼人

**✅ 成功的村民行为**:
- 认真听取每个人的发言，记录可疑点
- 积极发言，贡献分析
- 跟随可信赖的神职投票
- 保护真神职，揭穿假神职
- 关键时刻坦诚村民身份

## 特殊技巧

**伪装神职吸引火力**:
- 暗示自己是神职
- 吸引狼人击杀你，保护真神职
- 风险：可能被好人误会，导致混乱

**观察投票站队**:
- 记录每轮投票情况
- 分析谁总是跟谁站一队（可能是狼队）
- 找出投票矛盾者（可能是狼人）

**配合神职连线**:
- 如果预言家或其他神职跳出，坚定支持
- 用投票帮助神职带领好人阵营
- 关键时刻用村民身份换取信任

**最后一轮决策**:
- 如果游戏进入最后一轮，村民的投票可能决定胜负
- 冷静分析，投出最可疑的狼人
- 不要被狼人的煽动性发言误导
